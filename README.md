# Proyecto-Integrador-TQA

Documentos, entregables y evidencias del Proyecto Integrador para la materia
Testing y Quality Assurance.

El sistema bajo prueba es Ritmo Activo, una aplicación web de comercio electrónico
y CRM para una zapatería. En este repositorio se publican el plan de pruebas, los
casos de prueba diseñados, los registros de ejecución, los reportes de defectos y
las capturas de evidencia de cada entregable.

Materia: Testing, Quality Assurance
Carrera de Ingeniería en Sistemas, Universidad Privada Franz Tamayo
